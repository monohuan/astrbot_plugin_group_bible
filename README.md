# astrbot_plugin_group_bible

群聊消息收录与随机爆典插件，适配 AstrBot 4.28.x 与 aiocqhttp/NapCat。

单条圣经采用适合手机阅读的聊天气泡样式渲染，头像位于左侧，作者名后显示原消息时间；列表页继续使用紧凑的 mutsumi_dark 风格。

## 指令

- 引用消息后 `/入典` 或 `/gbible add`
- `/爆典` 或 `/gbible random`
- `/删典 #ID` 或 `/gbible del #ID`
- `/群圣经` 或 `/gbible`
- `/群圣经帮助` 或 `/gbible help`
- `/群圣经列表 [页码]` 或 `/gbible list [页码]`
- `/群圣经 #ID` 或 `/gbible #ID`
- `/故事 [方向关键词]` 或 `/gbible story [方向关键词]`

入典权限等级：`0` 仅 AstrBot 管理员，`1` 增加群主和群管理员，`2` 所有成员。

戳一戳机器人时，如果当前群已有圣经，插件随机发送一条并终止默认 LLM 对话；如果当前群没有圣经，事件继续交给 AstrBot 正常对话。

爆典采用按群独立、持久化的“洗牌袋”伪随机。可在插件 WebUI 设置每个随机池包含几套典；例如设为 3，则每条典在一轮池中各有 3 份，整池抽完后才重新洗牌。也可设置随机池定时重置分钟数，`0` 表示不按时间重置。抽取进度保存在 SQLite 中，插件重载或 AstrBot 重启不会重置；新入典会按配置套数加入当前轮，删典会自动从待抽列表剔除。

故事功能会从当前群的典中无重复随机抽取若干条，并调用当前会话配置的聊天模型编写一则短故事。模型会优先以典的作者作为主角或配角，结果固定为 `《故事名称》`、`#01/#02`（本次使用的典 ID）和故事正文三部分；合并转发的第一条是故事，后续按 ID 行顺序附上本次使用的所有典，并沿用单条典的卡片渲染样式。合并转发失败时会依次发送故事与典。抽取数量上下限在插件配置页设置，默认 `3-6` 条；命令后的文字作为故事方向关键词，例如 `/故事 校园 悬疑` 或 `/gbible story 赛博朋克`。图片典会优先使用 AstrBot 默认图片转述模型提取人物、动作、表情、文字梗等故事线索，再与文字典统一交给故事模型；故事模型不会获知线索来自图片，并会将其改写成情节、动作或对白，而不是生硬转述画面。未单独配置转述模型时，仅在当前会话模型明确支持图片的情况下识图。如果没有可用的多模态模型，则自动退化为仅抽取文字典。故事抽样独立于爆典洗牌池，不会改变后续爆典顺序。

## LLM Poke 兼容

兼容 `astrbot_plugin_poke_to_llm`（以及默认优先级的同类 LLM Poke 插件）：群圣经监听优先级为 `10000`。当前群有条目时由群圣经先行接管并停止传播，确保不会同时爆典和生成 LLM 回复；当前群没有条目时不修改 `should_call_llm`、不停止事件，完整交给 LLM Poke 插件处理。

## WebUI

在 AstrBot 管理面板的插件页面中打开“群圣经管理”。管理页复用 Dashboard 登录鉴权，不开放独立端口，支持：

- 查看总条目数和收录群数
- 按群筛选、关键词或编号搜索、分页浏览
- 查看作者、收录者、时间和图片数量
- 从管理页删除条目
- 修改入典权限、戳一戳开关与冷却、随机池、故事抽取范围、内容限制和卡片编号显示
